# CoCo VPN

کلاینت VPN برای اتصال به سرورهای شخصی و مدیریت اتصال‌های VPN. این پروژه بر پایهٔ کد متن‌باز [Amnezia VPN Client](https://github.com/amnezia-vpn/amnezia-client) ساخته شده و با نام و رابط CoCo VPN توسعه داده می‌شود.

> **وضعیت پروژه:** در حال توسعه و آزمایش است. نسخهٔ فعلی هنوز برای انتشار عمومی یا استفادهٔ بدون آزمون نهایی آماده نیست.

## امکانات فعلی

- اتصال به سرورهای VPN شخصی و پشتیبانی از پروتکل‌های موجود در پروژه، از جمله OpenVPN، WireGuard، AmneziaWG و XRay.
- رابط برنامه به دو زبان فارسی و انگلیسی محدود شده است.
- بخش اولیهٔ مدیریت حساب‌های اتصال سرور شخصی، شامل ساخت گروهی حساب و انتخاب چند پروتکل برای هر حساب.
- امکان ساخت پیش‌نمایش محتوای اشتراک‌گذاری با قالب و QR برای حساب‌های ایجادشده.

قابلیت‌های تازهٔ مدیریت حساب و اشتراک‌گذاری هنوز باید روی ویندوز و سپس روی سیستم‌عامل‌های دیگر آزمایش شوند. جزئیات و نتیجهٔ آزمون‌ها با پیشرفت پروژه به‌روزرسانی می‌شود.

## سیستم‌عامل‌ها

کد پروژه برای Windows، macOS، Linux، Android و iOS بخش‌هایی دارد. آماده‌بودن کد برای یک سیستم‌عامل به معنی وجود نسخهٔ نصب‌شدنی یا آزموده‌شدهٔ آن نیست؛ وضعیت هر نسخه باید جداگانه بررسی شود.

## دریافت سورس

پس از دریافت مخزن، submoduleها را نیز دریافت کنید:

```bash
git submodule update --init --recursive
```

## پیش‌نیازهای ساخت

- CMake
- کامپایلر متناسب با سیستم‌عامل
- Qt 6.10 یا جدیدتر، همراه با ماژول‌های موردنیاز پروژه
- Conan

برای ساخت در Windows از اسکریپت زیر استفاده کنید:

```bat
deploy\build.bat
```

برای ساخت در Linux و macOS:

```bash
deploy/build.sh
```

اسکریپت‌های پوشهٔ `deploy` گزینه‌های بیشتری برای ساخت نصب‌کننده و نسخه‌های پلتفرم‌های مختلف دارند. پیش‌نیازهای دقیق و نسخه‌های ابزارها ممکن است با تغییر پروژه به‌روز شوند.

## زبان رابط

در نسخهٔ فعلی برنامه، فقط فارسی و انگلیسی ارائه می‌شود. فایل‌های ترجمهٔ زبان‌های دیگر ممکن است هنوز در سورس باشند، اما در رابط برنامه فعال نیستند.
