# Plans

Implementation plans written by the `planner` agent (`.claude/agents/planner.md`) before coding,
kept here when the owner should review them. One file per plan: `<roadmap-or-KI-id>-<slug>.md`, for
example `W1-webpack-sign-in.md` or `KI-03-batch-off-gui-thread.md`, in the planner's output format.

A plan is a proposal, not a record of what was built: when its slices merge, `CHANGELOG.md` and the
canonical documents (`ARCHITECTURE.md`, `docs/ai/*`) carry the truth. Delete a plan once all its slices
are merged or it is abandoned.
